# Learn Chinese Writing
A Mixed-Reality experience for Chinese writing learning. Write in mid-air with your fingertip and manage your progress with intuitive hand gestures - no stylus required. 

https://github.com/user-attachments/assets/cbc85ccb-aef7-4954-ac66-7d4c86d630af

## Features

- **Hand-gesture interaction**: Uses Meta Interaction SDK with custom hand pose recognition to write and erase Chinese characters in mid-air
- **Gamification**: Designed a panda avatar to guide users' writing practice
